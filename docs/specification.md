## 2. 画面仕様

### 2.1 共通ヘッダー（タブバー）

- 常時画面最上部に固定表示（`position: sticky`）
- **入庫タブ**（🚗 入　庫）: `entry-view` を表示
- **一覧タブ**（📋 一覧・出庫）: `list-view` を表示し `renderList()` を呼び出す
- アクティブなタブはオレンジ下線・白テキスト・半透明背景で強調

### 2.2 入庫フォーム（entry-view）

#### データ保存バッジ
- 「💾 データはこの端末に自動保存されます」を常時表示
- **🗑️ データ全削除** ボタン: 確認モーダルを表示後に全削除（F10）

#### 入力フィールド

| フィールドID | ラベル | 入力形式 | バリデーション |
|---|---|---|---|
| `visitor-name` | 訪問者名（会社名） | テキスト | 省略可（空欄時は「不明」で登録） |
| `destination` | 訪問先（担当部署・担当者） | テキスト | 省略可（空欄時は「不明」で登録） |
| `plate-number` | ナンバープレート | 数字（inputmode=numeric） | 必須、1〜4桁の数字のみ |

#### ナンバー入力時の自動入力・自動登録（F11）

`plate-number` に数字を入力すると、1000ms後に以下の処理を実行する（デバウンス）。

**入庫中ナンバーの場合（同一ナンバーで `outTime=null` のレコードが存在）**:

1. 入力値が `/^\d{1,4}$/` に一致しない場合は処理しない
2. 入庫中レコードの `name`・`dest` を取得
3. トースト「⚠️ このナンバーはすでに入庫中です」を表示
4. 取得した `name`・`dest` で新規レコードを自動登録
5. フォームをリセットし、成功メッセージ「✅ 過去データから自動入庫しました（name）」を3秒表示

**過去に入庫履歴があるナンバーの場合**（入庫中でない）:

1. 入力値が `/^\d{1,4}$/` に一致しない場合は処理しない
2. 全レコードから同一ナンバーのデータを検索
3. 一致なし → 処理終了
4. 日付・入庫時刻の降順でソートし最新レコードを取得
5. 最新レコードの `name`・`dest` で新規レコードを自動登録
6. フォームをリセットし、成功メッセージ「✅ 過去データから自動入庫しました（name）」を3秒表示

> **注意**: 「入庫　登　録」ボタンによる手動登録では、入庫中のナンバーは重複登録できない（トーストを表示して終了）。自動入力（デバウンス処理）のみ重複を許容する。

#### 入庫登録ボタン

- 「入　庫　登　録」ボタン押下で `register()` を実行
- バリデーションエラー時はトーストで通知
- 成功時: ✅ 成功メッセージを3秒表示 → フォームリセット

### 2.3 一覧・出庫画面（list-view）

#### ヘッダー行

- 左: 日付ラベル（通常表示時）または「🔍 フィルター内容」（絞り込み時）
- 右: 📂 CSV読込 ボタン / 📥 CSV出力 ボタン

#### ナンバー検索（F05）

| 入力 | 動作 |
|---|---|
| 数字（部分一致） | 先頭ゼロを除去して全期間レコードから部分一致検索 |
| `0000` | 全期間の全データを表示 |
| 空欄 | ナンバーフィルターなし |

先頭に `0` を含む入力（`01`, `011` など）は完全一致検索（先頭ゼロを除去した値と完全一致）。

#### 日付検索（F12）

- 入力欄ID: `search-date`（`type="text"`、`maxlength="10"`）
- **デフォルト値**: タブを開いた時・ページロード時に当日の日付を自動設定
- **対応フォーマット**:

| 入力例 | 説明 |
|---|---|
| `20260601` | 8桁の数字 → 入力完了時に自動で `2026/06/01` に整形 |
| `2026/06/01` | スラッシュ区切り |
| `2026-06-17` | ハイフン区切り |

- **入力制限**: 年は4桁まで、月・日は各2桁まで自動制限
- **検索基準**: 入庫日（`date` フィールド）で絞り込む
- **✕ クリア**: 日付欄を空にしてプレースホルダー「例：20260601 または 2026/06/01」を表示
- クリア後に欄をタップすると再入力可能

#### ステータスフィルター（F13）

3つのボタンで一覧をステータス別に絞り込む。

| ボタン | 表示対象 | デフォルト |
|---|---|---|
| すべて | 全レコード | ✓（初期選択） |
| 入庫中 | `outTime === null` のレコードのみ | — |
| 出庫済み | `outTime !== null` のレコードのみ | — |

- 選択中のボタン: 紺色（`background: #0d47a1`、白文字）
- 非選択のボタン: グレー（`background: #e0e0e0`、濃いグレー文字）
- 日付・ナンバーフィルターと組み合わせ可能

#### 複合フィルターの組み合わせ例

| ナンバー | 日付 | ステータス | 結果 |
|---|---|---|---|
| 空欄 | 当日 | すべて | 今日の全データ（通常表示） |
| 空欄 | 当日 | 入庫中 | 今日の入庫中のみ |
| 空欄 | 2026-06-16 | 出庫済み | 6月16日の出庫済みのみ |
| 1234 | 空欄 | すべて | 全期間でナンバー「1234」を含む全データ |
| 1234 | 2026-06-17 | すべて | 6月17日でナンバー「1234」を含む全データ |
| 0000 | 任意 | 入庫中 | 全期間の入庫中のみ |

#### 統計カード

| カード | 表示内容 |
|---|---|
| 本日合計 | 表示中レコードの総件数 |
| 入庫中 | 表示中で `outTime === null` のレコード数（青数字） |
| 出庫済み | 表示中で `outTime !== null` のレコード数（グレー数字） |

#### 記録カード

各レコードを1カードで表示。

```
┌─────────────────────────────────────┐
│ [訪問者名]              [ナンバー]  │
│ 訪問先：〇〇部 ／ 📅 2026-06-10    │※絞り込み時のみ日付表示
│ 入庫 09:30 ／ 出庫 11:45  [出庫済み]│
└─────────────────────────────────────┘
```

- 入庫中: オレンジ「出　庫」ボタンを右側に表示
- 出庫済み: グレー「出庫済み」バッジを表示
- 絞り込み時: カードに青枠・水色背景を付けて検索結果を強調
- カードタップ（タッチスクロール10px未満）: 編集モーダルを開く

### 2.4 編集モーダル

カードタップで下部からスライドアップして表示。

| フィールド | 内容 |
|---|---|
| 訪問者名 | テキスト入力（必須） |
| 訪問先 | テキスト入力 |
| ナンバー | 数字1〜4桁（必須） |
| 入庫時刻 | time型 |
| 出庫時刻 | time型（未出庫は空欄） |

- **保　存**: バリデーション後に更新、一覧を再描画、トースト「修正しました」
- **削　除**: `confirm()` ダイアログ後に削除
- **↩️ 入庫中に戻す**: 出庫済みレコードのみ表示。`outTime` を `null` にリセット（F07）
- オーバーレイクリックまたは「✕」ボタンでモーダルを閉じる

### 2.5 CSV出力モーダル（F08）

| ボタン | 動作 |
|---|---|
| 📅 今日のデータ | 当日のレコードをCSV出力 |
| 🗓️ 日付を指定して出力 | 日付ピッカーを表示し指定日のレコードを出力 |
| 📋 全期間のデータ | 全レコードを日付・入庫時刻順でCSV出力 |

ファイル名: `入出庫記録_{日付 or "全期間"}.csv`  
該当データなし: トースト「該当するデータがありません」でキャンセル

### 2.6 CSV読み込みモーダル（F09）

| オプション | 動作 |
|---|---|
| 🔄 全データを上書き（置き換え） | 既存の全レコードを削除してCSVのデータで置き換え |
| ➕ 既存データに追記（重複除外） | 日付・入庫時刻・ナンバーの3キーで重複判定し、新規レコードのみ追加 |

**CSVパース仕様**
- BOM（`﻿`）を除去してから処理
- 1行目（ヘッダー行）をスキップ
- 列数6未満・必須列（date, inTime, plate）が空の行はスキップ
- ダブルクォートを除去してフィールド値を取得

### 2.7 確認モーダル（全削除確認、F10）

- 「本当にすべてのデータを削除しますか？この操作は元に戻せません。」
- **キャンセル** / **全削除する** の2択
- 全削除後: localStorage削除 → 一覧リセット → トースト表示

## 3. バリデーション仕様

### 3.1 入庫登録

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| `plate-number` | 必須、`/^\d{1,4}$/` に一致 | 「ナンバーを1〜4桁の数字で入力してください」 |
| `visitor-name` | 省略可（空欄時に「不明」を設定） | — |
| `destination` | 省略可（空欄時に「不明」を設定） | — |

### 3.2 編集モーダル

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| `edit-name` | 必須 | 「訪問者名を入力してください」 |
| `edit-plate` | 必須、`/^\d{1,4}$/` に一致 | 「ナンバーは1〜4桁の数字で入力してください」 |

### 3.3 日付検索入力

| 入力 | 処理 |
|---|---|
| 数字・`/`・`-` 以外の文字 | 入力時に自動除去 |
| 年部分が5桁以上 | 4桁に自動切り詰め |
| 月・日部分が3桁以上 | 2桁に自動切り詰め |
| 8桁の連続数字（YYYYMMDD） | `YYYY/MM/DD` 形式に自動整形 |
| maxlength | 10文字まで |

## 5. データ永続化仕様

- **保存先**: `localStorage`（キー: `parking_records`）
- **保存タイミング**: 入庫登録・出庫処理・編集保存・削除・CSV読み込みの都度
- **読み込みタイミング**: ページロード時
- **クリア**: 「データ全削除」操作時に `localStorage.removeItem(STORAGE_KEY)` を呼び出す
- **障害対応**: `try-catch` で囲み、JSON解析失敗時は空配列を返す
