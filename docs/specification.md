# 車両入出庫管理アプリ 機能仕様書

**バージョン**: 1.1  
**作成日**: 2026-06-10  
**更新日**: 2026-06-10（セキュリティ修正）

---

## 1. 機能一覧

| # | 機能 | 説明 |
|---|---|---|
| F01 | 入庫登録 | 訪問者情報とナンバーを入力して入庫記録を作成 |
| F02 | ナンバープレートOCR | カメラ撮影または写真選択でナンバーを自動読み取り |
| F03 | 出庫処理 | 一覧画面から「出庫」ボタンを押して出庫時刻を記録 |
| F04 | 今日の一覧表示 | 当日の入出庫記録と統計を表示 |
| F05 | ナンバー検索 | 数字入力で全期間から車両を検索 |
| F06 | 記録の編集・削除 | カードタップでモーダルを開き情報を修正または削除 |
| F07 | 入庫中に戻す | 誤出庫したレコードを未出庫状態に戻す |
| F08 | CSV出力 | 今日・日付指定・全期間のデータをCSVでダウンロード |
| F09 | CSV読み込み | CSVファイルをインポート（上書き or 追記） |
| F10 | データ全削除 | localStorageの全レコードを削除 |

## 2. 画面仕様

### 2.1 共通ヘッダー（タブバー）

- 常時画面最上部に固定表示（`position: sticky`）
- **入庫タブ**（🚗 入　庫）: `entry-view` を表示
- **一覧タブ**（📋 一覧・出庫）: `list-view` を表示し `renderList()` を呼び出す
- アクティブなタブはオレンジ下線・白テキスト・半透明背景で強調

### 2.2 入庫フォーム（entry-view）

#### データ保存バッジ
- 「💾 データはこの端末に自動保存されます」を常時表示
- **🗑️ データ全削除** ボタン: 確認モーダルを表示後に全削除（F10）

#### 入力フィールド

| フィールドID | ラベル | 入力形式 | バリデーション |
|---|---|---|---|
| `visitor-name` | 訪問者名（会社名） | テキスト | 省略可（空欄時は「不明」で登録） |
| `destination` | 訪問先（担当部署・担当者） | テキスト | 省略可（空欄時は「不明」で登録） |
| `plate-number` | ナンバープレート | 数字（inputmode=numeric） | 必須、1〜4桁の数字のみ |

#### カメラエリア

- **📷 カメラ撮影**: デバイスの背面カメラを起動（`capture="environment"`）
- **🖼️ 写真から選ぶ**: ギャラリー・ファイルブラウザを起動
- 画像選択後、プレビュー表示 → OCR処理中アニメーション → 結果をplate-numberに自動入力

#### OCR結果表示

| 状態 | 表示内容 |
|---|---|
| 処理中 | 🔍 ナンバーを読み取り中… |
| 成功 | 「読み取り結果：**1234** （修正可能）」 |
| 失敗 | 「読み取りできませんでした。手動で入力してください。」（赤文字） |

#### 入庫登録ボタン

- 「入　庫　登　録」ボタン押下で `register()` を実行
- バリデーションエラー時はトーストで通知
- 成功時: ✅ 成功メッセージを3秒表示 → フォームリセット

### 2.3 一覧・出庫画面（list-view）

#### ヘッダー行

- 左: 日付ラベル（例: `2026年6月10日（水）`）または検索中は「🔍 ナンバー検索結果」
- 右: 📂 CSV読込 ボタン / 📥 CSV出力 ボタン

#### ナンバー検索（F05）

| 入力 | 動作 |
|---|---|
| 数字（部分一致） | 先頭ゼロを除去して全期間レコードから部分一致検索 |
| `0000` | 全期間の全データを表示 |
| 空欄 | 通常モード（当日のみ表示）に戻る |

先頭に `0` を含む入力（`01`, `011` など）は完全一致検索（先頭ゼロを除去した値と完全一致）。

#### 統計カード

| カード | 表示内容 |
|---|---|
| 本日合計 | 当日の全レコード数（検索中は検索結果件数） |
| 入庫中 | `outTime === null` のレコード数（青数字） |
| 出庫済み | `outTime !== null` のレコード数（グレー数字） |

#### 記録カード

各レコードを1カードで表示。

```
┌─────────────────────────────────────┐
│ [訪問者名]              [ナンバー]  │
│ 訪問先：〇〇部 ／ 📅 2026-06-10    │※検索時のみ日付表示
│ 入庫 09:30 ／ 出庫 11:45  [出庫済み]│
└─────────────────────────────────────┘
```

- 入庫中: オレンジ「出　庫」ボタンを右側に表示
- 出庫済み: グレー「出庫済み」バッジを表示
- カードタップ（タッチスクロール10px未満）: 編集モーダルを開く

### 2.4 編集モーダル

カードタップで下部からスライドアップして表示。

| フィールド | 内容 |
|---|---|
| 訪問者名 | テキスト入力（必須） |
| 訪問先 | テキスト入力 |
| ナンバー | 数字1〜4桁（必須） |
| 入庫時刻 | time型 |
| 出庫時刻 | time型（未出庫は空欄） |

- **保　存**: バリデーション後に更新、一覧を再描画、トースト「修正しました」
- **削　除**: `confirm()` ダイアログ後に削除
- **↩️ 入庫中に戻す**: 出庫済みレコードのみ表示。`outTime` を `null` にリセット（F07）
- オーバーレイクリックまたは「✕」ボタンでモーダルを閉じる

### 2.5 CSV出力モーダル（F08）

| ボタン | 動作 |
|---|---|
| 📅 今日のデータ | 当日のレコードをCSV出力 |
| 🗓️ 日付を指定して出力 | 日付ピッカーを表示し指定日のレコードを出力 |
| 📋 全期間のデータ | 全レコードを日付・入庫時刻順でCSV出力 |

ファイル名: `入出庫記録_{日付 or "全期間"}.csv`  
該当データなし: トースト「該当するデータがありません」でキャンセル

### 2.6 CSV読み込みモーダル（F09）

| オプション | 動作 |
|---|---|
| 🔄 全データを上書き（置き換え） | 既存の全レコードを削除してCSVのデータで置き換え |
| ➕ 既存データに追記（重複除外） | 日付・入庫時刻・ナンバーの3キーで重複判定し、新規レコードのみ追加 |

**CSVパース仕様**
- BOM（`﻿`）を除去してから処理
- 1行目（ヘッダー行）をスキップ
- 列数6未満・必須列（date, inTime, plate）が空の行はスキップ
- ダブルクォートを除去してフィールド値を取得

### 2.7 確認モーダル（全削除確認、F10）

- 「本当にすべてのデータを削除しますか？この操作は元に戻せません。」
- **キャンセル** / **全削除する** の2択
- 全削除後: localStorage削除 → 一覧リセット → トースト表示

## 3. API仕様

### 3.1 OCRエンドポイント

**URL**: `https://us-central1-parking-2bd69.cloudfunctions.net/ocrPlate`

**メソッド**: POST

**リクエストヘッダー**:
```
Content-Type: application/json
```

**リクエストボディ**:
```json
{
  "b64": "<base64エンコードされた画像データ>",
  "mediaType": "image/jpeg"
}
```

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `b64` | string | ○ | 画像をbase64エンコードしたデータ（DataURLのカンマ以降） |
| `mediaType` | string | △ | MIMEタイプ。省略時は `image/jpeg` |

**レスポンスボディ（成功）**:
```json
{ "number": "1234" }
```

**レスポンスボディ（読み取り不可）**:
```json
{ "number": null }
```

**エラーレスポンス**:

| HTTPステータス | 説明 |
|---|---|
| 403 | 許可されていないオリジンからのリクエスト |
| 405 | POST以外のメソッド |
| 400 | `b64` が指定されていない |
| 500 | APIキー未設定 / OCR処理エラー |
| 502 | OpenAI APIエラー |

**許可オリジン**:

| オリジン | 用途 |
|---|---|
| `https://pcmnb.github.io` | 本番（GitHub Pages） |
| `http://localhost:5000` | ローカル開発（Firebase Emulator） |
| `http://127.0.0.1:5000` | ローカル開発（Firebase Emulator） |

## 6. データ永続化仕様

- **保存先**: `localStorage`（キー: `parking_records`）
- **保存タイミング**: 入庫登録・出庫処理・編集保存・削除・CSV読み込みの都度
- **読み込みタイミング**: ページロード時
- **クリア**: 「データ全削除」操作時に `localStorage.removeItem(STORAGE_KEY)` を呼び出す
- **障害対応**: `try-catch` で囲み、JSON解析失敗時は空配列を返す
